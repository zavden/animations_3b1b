This repository is published under the **[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)** license (Attribution-NonCommercial-ShareAlike), the same as [3b1b/videos](https://github.com/3b1b/videos), which the scenes come from. It lists the attributions of the assets that are **included** (level 1), those that are **downloaded** during setup (level 2) and those that were **replaced** by original material (level 3). The full policy and the asset-by-asset classification are in `_tools/assets_licencias/assets_referencia.csv` (column `nivel`).

The third-party photos and data of sections 2 to 6 **keep their own license**; they do not pass to the repo's CC BY-NC-SA. The photos are downloaded with `_lib/assets/generated/replacements/photos/make_replacement_photos.py`, which checks the license against the Wikimedia Commons API on every run and leaves the author, license and URL in `photos_sources.json` (where this list comes from). The real photos and textures that were missing in 3b1b/videos (astronomy, historical portraits, objects) are downloaded with `_lib/assets/generated/replacements/downloads/make_downloaded_assets.py`, which verifies the license in the same way and leaves `downloads_sources.json`.

## 1. Work by 3Blue1Brown

- **Author:** Grant Sanderson / 3Blue1Brown. **License:** [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) (`LICENSE.txt` of [3b1b/videos](https://github.com/3b1b/videos)).
- **What is included:** the code of the scenes (`1_unmodified/`, `2_modified/`, `3_not_rendering/`, `4_interactive/`, `_work/`), the `_lib/custom/` package and the following assets and data from the original repo:
  - Data: `language_tree/` (language families, tree layout, list of languages), `text_data/th_followers.txt`, `huffman_table.json`, `text_data/rights_of_man.txt` (the 1789 Declaration is in the public domain; the file comes from the repo), `qwen_completions_713b01ef65.json` (output of Qwen2.5-0.5B, Apache 2.0, generated by Grant), and the last line of `text_data/training_data_examples.txt` ("Smart models are less surprised, poor ones are perplexed."; the rest of the file is our own, section 7).
- **What was modified:**
  - Each scene was extracted to a file of its own and adapted to ManimGL 1.7.2; each change to the code is marked with `# CHANGE` and listed in the file's header.
  - `_lib/custom/`: bug fixes to the repo's own code (`drawings.py`, `pi_creature_scene.py`, ...), marked `# CHANGE (converted/_lib)` (see `README.md`). `_lib/manim_imports_ext.py` and `_lib/legacy_vector_field.py` are our adaptations.
  - The scenes' data are copied next to each one without changes; the Wordle derivatives are regenerated (section 7).
- **What is not redistributed:** the pi creatures (they were only in the first commit of 3b1b/videos; Grant removed them afterwards) nor the 3b1b logo. They are replaced by original material (section 7).
- This redistribution is non-commercial, keeps the license (ShareAlike) and does not imply endorsement by 3Blue1Brown.
