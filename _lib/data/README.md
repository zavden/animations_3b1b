# _lib/data

Data that 3b1b's `custom/` library reads from `get_directories()["data"]`.

- `top_patrons.txt`, `hardcoded_patrons.txt`, `patron_name_replacements.json`:
  **placeholders** for the end screens (`PatreonEndScreen`, `EndScreen`).
  The real names of the patrons are not public; here they are "Mecenas 001…240" (Spanish for "Patron").
